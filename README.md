# architecture-area-calculator
A command-line Python tool that calculates and categorizes room areas for architectural programming.

## Features
- Add rooms with name, category, and area
- Calculate total project area
- Summarize area by room category
- Compare total area against a target area
- Load a sample architectural program

## Skills Practiced
- Python functions
- Lists and dictionaries
- Loops and conditionals
- User input validation
- Basic summary reporting

## How to Run
```bash
python architecture_area_calculator.py
